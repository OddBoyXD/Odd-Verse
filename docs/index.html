FAQ

Frequently Asked Questions

Is Odd Verse truly 100% free with zero ads? +
Yes, 100%. Odd Verse is an open-source project. It contains zero third-party telemetry, zero banner ads, and zero subscription barriers.
Which APK should I install on my phone? +
Choose the 64-bit ARM (arm64-v8a) build for almost all modern Android phones. If in doubt, the Universal APK will run on all devices.
How does Indic transliteration work? +
Odd Verse runs a local lightweight Dart phonetics parser that converts synced Hindi, Punjabi, and Gurmukhi script lyrics into easily readable English/Roman characters line-by-line in real time.
