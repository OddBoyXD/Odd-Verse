COMMON QUESTIONS

Frequently Asked Questions

Is Odd Verse completely free with zero ads? +
Yes, 100%. Odd Verse is an open-source music streaming client that does not contain any advertisements, third-party analytics trackers, or paid subscriptions.
Which APK should I download for my phone? +
For almost all modern Android phones produced in the last 6+ years, choose the 64-bit ARM (arm64-v8a) APK. If you're not sure, the Universal APK will run on any Android device.
How does Indic transliteration work? +
Odd Verse includes native phonetic transliteration algorithms that automatically convert synced Hindi, Punjabi, and Gurmukhi script lyrics into readable Latin/English alphabet characters in real-time.
Is Odd Verse safe to install on Android? +
Yes, every release APK is cryptographically signed with a secure master keystore and built directly through transparent GitHub Actions pipelines from the public source repository.
