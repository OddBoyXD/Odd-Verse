Some Android OEMs (Xiaomi, Samsung, OnePlus, Vivo) aggressively kill background processes. To ensure uninterrupted playback:

  1. Go to Settings > Apps > Odd Verse > Battery.
  2. Set Battery Usage to Unrestricted / No Restrictions.
  3. In Odd Verse Settings, enable Ignore Battery Optimizations.
