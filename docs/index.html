CORE ARCHITECTURE

ExoPlayer Turbo Audio Engine

Customized AndroidLoadControl parameters maintain an aggressive forward prefetch buffer. When you tap a track, playback starts within 150ms, while subsequent tracks in your queue are automatically pre-buffered in the background.

Zero Gap Playback Crossfade Support ExoPlayer 2.19
SMART LYRICS

Real-Time Indic Transliteration

An on-device phonetic translation engine converts synchronized lyrics from Devanagari (Hindi), Gurmukhi (Punjabi), and regional scripts into clean English Roman characters line by line.

FAQ

Frequently Asked Questions

Everything you need to know about safety, updates, and compatibility.

Is Odd Verse completely free with zero ads? +
Yes, 100%. Odd Verse is an open-source project created by OddBoyXD. It contains zero third-party telemetry, zero banner ads, zero audio interruptions, and zero subscription barriers. All source code is publicly inspectable on GitHub.
Which APK should I install on my phone? +
Choose the 64-bit ARM (arm64-v8a) APK for almost all modern Android phones produced since 2017 (Samsung, Pixel, Xiaomi, OnePlus, etc.). If you are unsure or installing on an uncommon device, install the Universal APK.
How does real-time Indic transliteration work? +
Odd Verse runs a local lightweight phonetic phoneme parser written in Dart. When playing songs with Devanagari (Hindi) or Gurmukhi (Punjabi) synced lyrics, it transliterates them on-the-fly into clean Roman/English characters in real time so you can sing along without needing to read native scripts.
Why does Google Play Protect show a notice during installation? +
Because Odd Verse is distributed directly via GitHub rather than the Google Play Store, Play Protect flags it as an "Unrecognized Developer". Odd Verse is cryptographically signed with our Master Keystore, contains no malware or trackers, and a formal verification appeal has been submitted to Google Play Protect. You can safely tap More Details > Install Anyway.
How do I update Odd Verse when new versions are released? +
Simply download the new APK version from our website or GitHub releases page and install it directly over your existing installation. Your local playlists, favorites, and settings will remain completely intact.
