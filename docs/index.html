0–0.5s playback threshold.

ExoPlayer starts playing audio within 150ms of tapping any track, pre-buffering upcoming queue items silently in the background.

Synchronized · Auto-snap

Lyrics with 3s snap cooldown.

Real-time viewport centering lyrics with smooth scrolling. Manual scrolling is respected with an intelligent 3-second inactivity auto-snap back to active playback.

  • SyncMicrosecond-accurate timestamp matching
  • RomanizationHinglish transliteration for Indic scripts
  • Tap-to-SeekTap any line to seek playback instantly
oddverse — lyrics-engine
$ oddverse sync-lyrics --auto-snap 3.0s
→ active line: [01:24.500] "I'm tryna put you in the worst mood, ah"
→ user manual scroll detected… pausing auto-scroll
✓ 3.0s inactive → smooth snap back to playhead [01:27.500]
