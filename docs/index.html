Frequently Asked Questions

Is Odd Verse truly 100% free with zero ads? +
Yes, unconditionally. Odd Verse is an open-source project. It contains zero third-party telemetry, zero banner ads, and zero subscription barriers.
Which APK should I download for my smartphone? +
For almost every modern smartphone manufactured in the last 6 years, choose the 64-bit ARM (arm64-v8a) build. If in doubt, the Universal APK will run on all devices.
How does Indic transliteration work? +
Odd Verse runs a local lightweight Dart phonetics parser that converts synced Hindi, Punjabi, and Gurmukhi script lyrics into easily readable English/Roman characters line-by-line in real time.
